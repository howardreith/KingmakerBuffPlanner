# Mr. Bard's Kingmaker Buff Planner 0.6.0

Owner-authorized full release. The owner requested merging the controller work
into the default branch and publishing a new version. This exact release has
not been run in the game. Publication does not establish native controller
qualification or completion of the full-controller acceptance matrix.

## Controller planner

- Adds a genuine selectable Buff Planner card to the native campaign menu,
  opening the planner directly. The displayed mapped shortcut remains available
  for quick Long / Important / Short access where conflict-free.
- Adds semantic controller focus over the shared workspace: catalogue filters,
  exact caster/source and recipient assignment, casting inspection and one-shot
  edits, recast/enhancements, ordering, removal, Undo, policies and recovery.
- Adds a controller-operated search character grid and scrollable descriptions,
  Resources and results. Physical typing is not the principal authoring route.
- Opens the same planner from the native controller spellbook footer, preserving
  native book switching and modal ownership. Follow the displayed mapped glyph.
- Repairs workspace TMP initialization beneath inactive panels and owns separate
  controller text materials. This addresses the reported spellbook-entry display
  failure in source; actual first/settled rendering still requires observation.
- Keeps the existing shared campaign profile, immediate autosave, exact casting
  choices, execution admission, Instant/Animated modes, availability policy and
  Stop behavior. Run releases editing ownership before a separate deliberate
  confirmation; navigating or focusing does not cast.
- Preserves the reviewed text-cancellation ordering and overlapping viewport-sized
  report scrolling, latest-refusal precedence and authoritative save status.

These are implemented paths, not a claim that controller-only authoring, native
card input, rendering or gameplay/resource outcomes have been demonstrated.
F01-F10 remain NOT_RUN. Initial testing should use a disposable campaign without
casting: card -> browse/search -> exact source/recipient -> autosave -> close/reopen,
then compare spellbook entry. Full graph/controller support is not certified.

## Upgrade and compatibility

Exit Kingmaker and back up the entire Mods/KingmakerBuffPlanner folder, including
UserSettings, outside Mods before updating. Install the named 0.6.0 ZIP with Unity
Mod Manager, not GitHub's Source code archives. The UMM ID, DLL/folder identity
and external campaign profiles remain unchanged. No accompanying Gunslinger or
Call of the Wild update is required by this standalone UI release; neither is
bundled. Existing working optional-mod load repairs are not modified.

The native mouse editor, HUD, hotkey and spellbook entry remain available.
No new controller-family, remapping, Steam Deck, Linux or console qualification
is implied. A retained Classic choice requires explicit review/consent for its
existing transition; it is never silently switched.

The established owner-authorized pre-runtime publisher route runs source
validation, the complete offline C# behavior suite, publisher gate tests, two

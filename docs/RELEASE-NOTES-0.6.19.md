# Kingmaker Buff Planner 0.6.19

Choose **Automatic**, **English**, or **简体中文** in the planner's Unity Mod Manager settings. Automatic uses Simplified Chinese when Kingmaker does and English for other game languages. The preference applies to planner controls, tooltips and messages. Spell, item and companion names still come from the game or their provider. Saved routine names keep their original spelling.

Existing-buff checks now use the ability's duration data, so changing the display language preserves skip and recast decisions. Language switching also preserves workspace navigation, and the controller waits for neutral input after IME composition.

This is an owner-authorized pre-runtime release. This exact release has not been run in the game. The earlier 0.6.19 candidate opened the Chinese workspace and found a spell by its Chinese name. Physical IME and controller input, manual layout inspection, and representative normal and extended casts still need in-game testing. Translation review was internal.

# Mr. Bard's Kingmaker Buff Planner 0.6.6

This owner-authorized stable release promotes the controller navigation repair
merged in PR #14. This exact release has not been run in the game. It is
published for the owner's native controller test; rendered focus, physical
input, and detailed controller acceptance remain unverified.

The controller workspace moves focus according to controls' on-screen
positions, starts on the selected buff when available, remembers position
within wide rows, and draws a persistent focus border. Right-stick scrolling
through text-only Inspector notices now preserves the scroll position without
allowing Confirm to activate a hidden acknowledgement button. The 2.1.5 UMM
minimum is unchanged; native Linux 2.1.5d behavior remains unverified.

The 0.6.5-alpha.1 preview and source review informed this release, but no
native test report for that alpha has been recorded. Follow the
[focused controller checklist](CONTROLLER-NAVIGATION-REPAIR-2026-10-20.md),
especially six seconds of Spells focus and scrolling through imported
Inspector notices. Use a disposable working save for any plan edit or run.
